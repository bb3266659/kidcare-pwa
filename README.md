# KidCare – บันทึกสุขภาพลูกน้อย (PWA)

แอปบันทึกอาการป่วย การกินยา น้ำหนัก และส่วนสูงของลูก ทำงานแบบ Offline-first
เก็บข้อมูลใน IndexedDB ของเครื่องเท่านั้น ไม่มีการส่งข้อมูลออกนอกเครื่อง

## ฟีเจอร์
- แยกการป่วยเป็น Episode (เริ่ม–ปิดเหตุการณ์) พร้อมประวัติย้อนหลัง
- บันทึกแบบมื้อเดียวหลายตัวยา: `13:00 น. | ยาลดไข้ 3.5 ml | ยาแก้ไอ 2.0 ml`
- บันทึกอาการ/อุณหภูมิ ณ เวลาเดียวกับมื้อยา
- กราฟน้ำหนักและส่วนสูงแยกแท็บ
- โปรไฟล์ลูก + อัปโหลดรูป (ย่อขนาดอัตโนมัติ)
- Backup / Restore เป็นไฟล์ .json
- Export สรุปให้คุณหมอ: PDF / ข้อความ / แชร์ / .txt

## Deploy บน GitHub Pages
1. สร้าง repo ใหม่ แล้ว push โค้ดทั้งหมด
2. Settings → Pages → Source: `Deploy from a branch` → `main` / `root`
3. เปิด URL ที่ได้บนมือถือ → กด "เพิ่มลงหน้าจอโฮม"
